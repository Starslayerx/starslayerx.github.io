### Conversions

- 函数 `strtol`
- 定义 `long int strtol(const char *nptr, char **endptr, int base);`

参数:

- `nptr`: 待转换字符串（以 `\0` 结束）
- `endptr`: 二级指针。若不为 `NULL`，函数会将指针指向**第一个无法转换的字符**地址存入其中
- `base`: 待转换字符串的进制基数（2~36），或者设置为 0 自动识别

---

执行规则：

1. 跳过空白
2. 检测符号 `+`/`-`
3. 判断进制 (`base == 0`)
   - `"0x"` 或 `"0X"` 开头，十六进制
   - `"0"` 开头，八进制
   - 其他，十进制

4. 转换数字
5. 更新 `endptr`，指向中断位置

返回值与错误处理：

| 情况                     | 返回值     | 错误码 `errno`         |
| :----------------------- | :--------- | :--------------------- |
| 转换成功                 | `long int` | 不变（使用前建议清零） |
| 未转换任何字符           | `0`        | 不变                   |
| 数值下溢 小于 `LONG_MIN` | `LONG_MIN` | `ERANGE`               |
| 数值上溢 大于 `LONG_MAX` | `LONG_MAX` | `ERANGE`               |

- `errno` 是 C 标准库中定义的一个整数全局变量，在 `<errno.h>` 中
- 当 C 库函数（如 `strtol`、`fopen`、`malloc`）出错时，系统会向该变量中写入一个错误码
- 程序启动是，该值默认值为 0

---

一般而言，`endptr` 会这样使用：

- `*endptr == "\0"` 表明 `*nptr` 为纯数字，不带任何多余字符
- 处理结尾末尾的单位，例如 `20MB` 这种
- 连续解析多个数字，例如 `100 120 130` 这样
- 区分真正的 0 和转换失败，用户输入 `"0"` 和 `"abc"` 都会返回 0，需要区分开。
  可以使用 `nptr == endptr` 来判断，相等说明转换失败，第一个字符不是数字
